System Setup

Is the whole chain set up right, end to end? This updates itself as you fix things.

    Your fingers

    There's no room for another finger — remove one first.

    FYI: Your fingerprints are recorded on the sensor itself, and your Mac never sees any fingerprint data.

    • Ring (or this page) never turns purple? The sensor isn't talking. Check all six wires — especially the white one. It's the one everyone skips, and without it the sensor can hear but can't speak.
    • Ring (or this page) turns yellow? The device matched a finger but couldn't reach your Mac. Make sure the helper is running.
    • Nothing on this page at all? The helper serves this page — if it stopped, so did this.
    • Need to change your password, or the pairing key? Both take one command — no re-provisioning, no reflashing your fingerprints.

    My ring is yellow — why?

    The gadget recognized a finger but couldn't reach your Mac. Either the helper isn't running — start it with .venv/bin/dashtouch run, or make that automatic with .venv/bin/dashtouch install-agent — or setup never finished on the Mac side (run ./setup). Either way, the yellow clears itself on the next successful touch — there's nothing to reset by hand.

    Your device says "Not connected"

    Check that the cable is seated firmly at both ends. Some USB-C cables carry power but no data — try the one you'd use for an external drive or camera instead, or grab a data-capable one if you're not sure yours qualifies. Still nothing? Try a different port; some hubs are picky.

    The ring (or this page) never turns purple

    The firmware can't reach the sensor — almost always a wiring problem. Count the wires: all six connected? The white one (touch power) is the classic miss — without it the sensor can hear commands but can't answer, so every symptom looks like a dead sensor even when it isn't. The Troubleshooting guide walks through it wire by wire.

    Changing your password or your pairing key

    To update the password the gadget types: change it in macOS System Settings first — this page and the gadget never change your actual Mac password, only what's typed on your behalf. Once that's done, run .venv/bin/dashtouch password. It prompts you twice (hidden, like a login) and only touches the Keychain entry — your fingerprints and pairing are untouched, and it takes effect on your very next touch.

    Did your password end up somewhere it shouldn't — typed into the wrong window, a chat box, a shared screen? Treat that old password as burned right away. Change it in System Settings, then run .venv/bin/dashtouch password. That's the whole fix — no re-provisioning, no reflashing.

    To rotate the pairing key (the shared secret the gadget and this Mac use to trust each other), run .venv/bin/dashtouch pairing. This one's heavier: it needs a reflash right after, or the gadget and this Mac will disagree and stop working. The command explains that up front and offers to flash for you on the spot.

    Pairing looks broken

    The gadget and this Mac are holding different keys, so every signature the gadget sends gets rejected. The classic cause: the pairing key got rotated (.venv/bin/dashtouch pairing, or a re-run of ./setup) but the flash step got skipped, so the board is still carrying the old key. See changing your password or your pairing key for the rotation & reflash steps.

    About autostart

    .venv/bin/dashtouch install-agent installs a login item that starts the helper automatically whenever you log in, so you don't have to remember to run it by hand. To undo it: .venv/bin/dashtouch uninstall-agent
